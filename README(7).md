# 🏥 Life Care Hospital Website

A modern, responsive hospital website concept for **Life Care Hospital**, located in **Bode Barsain Municipality-5, Saptari, Nepal**. The project is designed to make essential healthcare information easy to access across mobile phones, tablets, and desktop devices.

The interface focuses on clear emergency contact options, hospital information, services, departments, appointment requests, location access, and direct WhatsApp communication.

## ✨ Features

- Fully responsive layout for mobile, tablet, and desktop
- Modern healthcare-focused user interface
- 24/7 emergency contact visibility
- Mobile-friendly navigation menu
- Hospital services section
- Department listing section
- Patient-focused facilities section
- Appointment request form
- Direct call buttons
- WhatsApp contact integration
- Google Maps location integration
- Responsive hospital location map
- Scroll/reveal interface effects
- Custom favicon support
- SEO-friendly page title and meta description
- Accessible navigation structure

## 🧰 Technologies Used

- **HTML5** — page structure and semantic content
- **CSS3** — responsive layout, styling, animations, and UI components
- **JavaScript** — navigation, interactions, appointment handling, and dynamic behavior
- **Google Fonts** — Manrope and Noto Sans Devanagari
- **Google Maps** — hospital location and directions
- **WhatsApp** — direct patient communication
- **Unsplash** — demonstration healthcare imagery

## 🏥 Website Sections

### Home
Hero section with emergency access, appointment CTA, hospital availability, and quick-help information.

### About
Introduces the hospital website concept with a patient-first, mobile-friendly approach.

### Services
Includes demonstration service areas such as Emergency Care, General Medicine, Women & Child Care, and Diagnostics.

### Departments
Provides quick access to department placeholders including Cardiology, General Medicine, Pediatrics, Gynecology, Diagnostics, and Emergency.

### Facilities / Patient Experience
Highlights fast mobile navigation, one-tap emergency calling, and a responsive appointment experience.

### Appointment
Allows visitors to prepare an appointment request directly from the browser. This static demo does not store patient information on a server.

### Location
Includes the hospital address, direct calling option, Google Maps directions, and an embedded map.

### WhatsApp Contact
A floating WhatsApp interface allows visitors to start a direct conversation with the hospital.

## 🚀 Run Locally

No build tools or package installation are required.

1. Clone the repository:

```bash
git clone https://github.com/preamshah/Lifecare-hospital.git
```

2. Open the project folder:

```bash
cd Lifecare-hospital
```

3. Open `index.html` directly in your browser.

For a better development experience, you can also run the project with the **Live Server** extension in Visual Studio Code.

## 🌐 Deployment

Because this is a static website, it can be deployed on:

- GitHub Pages
- Hostinger
- Netlify
- Vercel
- Cloudflare Pages
- Any standard shared hosting service

For traditional hosting, upload the project files to the website's public web directory such as `public_html`.

## ⚠️ Important Notice

This repository is a **website redesign/demo concept**. Some clinical departments and service descriptions are illustrative placeholders and should be verified with Life Care Hospital before using the website as an official production healthcare source.

The appointment interface is front-end only and does not store patient information in a backend database.
